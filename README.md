# 🃏 Página de Baraja de Cartas Interactiva (*Card Deck Page*)

Proyecto web interactivo desarrollado para practicar conceptos avanzados de **HTML5**, **CSS3 (Flexbox y Variables Personalizadas)** y **JavaScript**.

---

## 🚀 Características del Proyecto

* **Diseño Flexbox:** Uso de contenedores flexibles (`display: flex`, `flex-wrap`, `justify-content`) para una alineación y distribución responsiva de las cartas.
* **Variables CSS (*Custom Properties*):** Estilos centralizados en `:root` para facilitar la personalización de tamaños, radios de bordes y sombras de las cartas.
* **Efecto 3D Interactivo:** Animación de giro (*flip*) en el eje Y utilizando propiedades 3D (`perspective` y `rotateY`).
* **Función de Barajado (*Shuffle*):** Lógica en JavaScript utilizando el DOM para desordenar y reordenar aleatoriamente la baraja en pantalla con un solo clic.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Estructura semántica)
* **CSS3** (Estilos, Flexbox y Transformaciones 3D)
* **JavaScript (ES6+)** (Interactividad y manipulación del DOM)
